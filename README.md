# ⛩️ Япония 2026 — Осака и Кансай

Персональный интерактивный путеводитель Александра и Риты.
Даты: **9–25 сентября 2026**. База: **Osaka, Tanimachi 6-chome**.

## Демо для показа другим

Отдельная копия без личных данных (не трогает галочки и настройки личного гида):

**https://sasharna45-web.github.io/japan-osaka-2026/demo/**

Подробности — в [`demo/README.md`](demo/README.md).

## Трекер дней и бюджета

Та же статика, что и гид — отдельная страница рядом с ним:

**https://sasharna45-web.github.io/japan-osaka-2026/tracker.html**

Локально: откройте `tracker.html` или `http://localhost:8000/tracker.html`.
Данные (галочки и траты) хранятся в браузере, как чек-листы гида.

## Как открыть

Просто откройте `index.html` в браузере (двойной клик).
Работает и на телефоне: скопируйте папку в телефон или откройте через любой облачный диск.

> Весь путеводитель работает офлайн (PWA + локальные шрифты).

### Локальный сервер (по желанию)

Если хотите, чтобы всё грузилось стабильнее, запустите простой сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Возможности

- 📅 **17 дней** — раскрывающиеся карточки с местами, часами, ценами и советами.
- ⏰ **Жёсткий тайминг** — забронированные мероприятия помечены (KIX 12:45, Harukas 17:00, USJ Express/SNW 11:50, Nijigen 10:30–14:00, Hello Kitty 14:30–16:30, Umeda Sky ~17:30, вылет 15:00).
- 🎯 **Фильтры по интересам** — Nintendo, JRPG, Hello Kitty, Sylvanian, фото, еда и др.
- 📍 **Google Maps** — кнопка «Открыть в Google Maps» и «Фотографии» в каждом месте.
- ✏️ **Изменить план** — можно менять порядок дней; изменения сохраняются в браузере (localStorage).
- 📊 **[Трекер](tracker.html)** — чек-листы по дням, учёт **рабочих йен** (бюджет **$3225**, резерв **$700–1000** долларами), плюс справочник цен/логистики.
- 📱 Тёмная тема, красные акценты, японский минимализм, адаптив под телефон.

## Структура проекта

```
japan-osaka-2026/
├── index.html         # личный гид (Япония)
├── china.html         # транзит Шанхай
├── tracker.html       # трекер дней и бюджета
├── update.html        # сброс кэша на телефоне
├── sw.js / manifest   # PWA / offline cache (v36)
├── css/               # styles, china, tracker
├── js/                # data, app, photos, china-*, tracker-*
├── vendor/fonts/      # офлайн Noto JP/SC
├── demo/              # публичная копия без личных данных
└── README.md
```

**Деньги:** всего **$3225** → резерв **$700–1000** долларами → в йены примерно **$2225–2525** (≈356–404k ¥ при ~160). Трекер считает рабочие йены.

**Как редактировать маршрут:** всё содержимое лежит в `js/data.js`.
Каждый день — объект с полем `places` (массив мест). Добавить место — просто
скопируйте блок и поменяйте поля (`name`, `emoji`, `desc`, `lat`, `lng`, `time`, `fixed`, `tags` …).

## Идея на будущее (Python-бэкенд)

Сейчас данные лежат в `data.js`. Когда захочешь попрактиковаться в бэкенде,
из этого же маршрута легко сделать API на **FastAPI**:

- вынести маршрут в `trip.json`;
- отдавать `GET /days`, `GET /days/{n}`, `GET /places?tag=nintendo`;
- фронтенд забирать данные через `fetch()` вместо статического файла.

Это отличная тренировка связки «модель данных → API → фронтенд». Скажи — покажу пошагово.
