Публичная копия для показа другим людям.

**Личный гид в корне репозитория не затрагивается.**

## Ссылка

После публикации `main`:

https://sasharna45-web.github.io/japan-osaka-2026/demo/

## Чем демо отличается от личного гида

| | Личный гид `/` | Демо `/demo/` |
|--|----------------|---------------|
| Имена | ваши | Alex & Maria |
| Адрес квартиры | реальный | обезличен |
| localStorage | `japan2026.*` | `japan2026demo.*` |
| Service Worker | свой | **нет** (чтобы не сбивать личный кэш) |
| Баннер | нет | красный **DEMO** |

Галочки чек-листа, порядок дней и настройки в демо **не смешиваются** с вашим приложением.

## Как открыть локально

```bash
python -m http.server 8000
```

Затем: http://localhost:8000/demo/
